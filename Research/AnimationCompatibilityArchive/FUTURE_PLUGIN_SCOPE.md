# Future Animation Transformation Tool

A separate Animation Transformation / Compatibility tool may eventually build on this research. Its potential scope includes an Animation Track Inspector, Skeleton Inspector, Bone Mask, component-level transform masks, skeleton and facial compatibility analysis, cross-rig compatibility masks, rest-pose compensation, selective retargeting, and full skeletal retargeting only if there is a justified implementation and validation path.

That future project must own its native animation-writing lifecycle and offer its own structural and in-game visual validation. It must not silently repair animation contents inside a path-repathing plugin.

Dancy Core may later add path-level male/female routing, but it must not claim that routing repairs skeleton compatibility.
